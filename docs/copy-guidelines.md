# 全站文案規範

## 品牌與語氣

網站中文名稱統一為「全台密室逃脫精選導覽」，英文識別為「The Escape Index」。整體語氣應清楚、務實、帶有解謎感；以協助玩家挑選主題為目的，不模擬玩家實測評論，也不使用未經證實的絕對承諾。

## 用語原則

| 類別 | 使用方式 | 避免使用 |
| --- | --- | --- |
| 主題資料 | 使用「主題」「店家」「工作室」「官方預約頁」。 | 將店家評分說成主題評分，或把分類標籤寫成劇情。 |
| 評價語氣 | 使用「具挑戰性」「適合新手」「場景營造具沉浸感」等中性描述。 | 「神作」「大推」「神還原」「爆評」「首選」等像未證實玩家評論的詞。 |
| 資料不確定性 | 一律使用「依官網公告」。 | 「待核對」「符核對」「依官網為主」等不一致寫法。 |
| 行動按鈕 | 導向店家時使用「前往官方預約頁」。 | 無法證實的「享獨家優惠」。 |
| 數字與單位 | 使用阿拉伯數字加完整量詞，例如「100 場主題」「5 個城市」。 | 無意義前導零、未說明的代碼或工程編號。 |

## 資訊安全線

不補寫未經來源支持的劇情、玩家心得、排隊狀況、空間條件或優惠內容。若資料來源不足，保留中性導覽句或顯示「依官網公告」。
